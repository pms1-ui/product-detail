# 카카오 톡딜 상세페이지

카카오 스토어 톡딜 묶음상품의 상세페이지를 제작·관리하는 프로젝트입니다.

---

## 왜 이런 방식인가?

카카오 스토어 상품상세 HTML 편집기는 `style` 속성 대부분을 필터링합니다. 인라인 CSS 레이아웃을 그대로 넣으면 모바일에서 깨집니다. 따라서 **디자인은 로컬 HTML로 작업하고, 최종 등록 시에는 이미지로 변환**합니다.

이 작업은 89개 상품의 가격 반영, 개별 이미지 캡처, 경로 매핑 등 대량 반복 작업이 수반되므로 **AI 에이전트(Kiro) 기반으로 진행해야 공수가 대폭 줄어들며, 수작업으로는 현실적으로 어렵습니다.**

## 작업 순서

### Step 1. 데이터 준비 (`01_data/`)

`new.xlsx`에 상품 데이터를 정리합니다.

| 열 | 내용 |
|----|------|
| D | 택가 (정상가) |
| E | 톡딜가 |
| G | 혜택가 (톡딜 혜택가) |

할인율 = `ROUND((1 - 혜택가/택가) × 100)`

### Step 2. 디자인 작업 (`02_source/`)

`02_source/작업용.html`을 브라우저에서 열고 디자인합니다. 인라인 CSS를 자유롭게 사용하세요. 이 단계에서는 카카오 편집기 제약을 신경 쓸 필요 없습니다.

### Step 3. 가격 반영 (`02_source/`)

에이전트에게 엑셀 기준으로 `작업용.html`의 가격을 일괄 업데이트 요청합니다.

### Step 4. 이미지 캡처 → `03_output/`

puppeteer로 `작업용.html`의 상단 영역 + 89개 카드를 각각 JPG로 캡처합니다.

### Step 5. 서버 업로드

| 용도 | 서버 경로 |
|------|-----------|
| 상단 프로모 이미지 | `img/outdoor2026/promotion/detail_image/` |
| 상품 카드 이미지 | `img/outdoor2026/promotion/cards/` |
| 상품 상세 HTML | `img/outdoor2026/promotion/kakao_detail/` |

### Step 6. 카카오 스토어 등록

`03_output/kakao_final_YYMMDD.html` 내용을 카카오 스토어 상품상세 HTML 편집기에 붙여넣기. **모바일 미리보기 필수 확인.**

## 수정이 필요할 때

| 변경 사항 | 해야 할 일 |
|-----------|------------|
| 가격 변경 | 엑셀 수정 → 작업용.html 반영 → 카드 이미지 재캡처 → 서버 재업로드 |
| 디자인 수정 | 작업용.html 수정 → 해당 영역 이미지 재캡처 → 서버 재업로드 |
| 컬러칩 변경 | 작업용.html에서 hex 값 수정 → 해당 카드 재캡처 |

---

## 주의사항

1. 카카오 편집기에 인라인 style HTML 직접 넣기 **금지** — 반드시 이미지로 변환
2. 고정 px 너비 사용 금지 — 이미지 기반이면 모바일 자동 스케일
3. 톡채널 버튼에 `<a href="플친URL">` 링크 필수
4. 구성 86~89 (양말)은 혜택가 없이 톡딜가만 노출
5. 최종 파일명 규칙: `kakao_final_YYMMDD.html`
