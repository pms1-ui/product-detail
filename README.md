# 카카오 톡딜 상세페이지

카카오 스토어 톡딜 묶음상품의 상세페이지를 제작·관리하는 프로젝트입니다.

---

## 왜 이런 방식인가?

카카오 스토어 상품상세 HTML 편집기는 `style` 속성 대부분을 필터링합니다. 인라인 CSS로 만든 레이아웃을 그대로 넣으면 모바일에서 깨집니다. 따라서 **디자인은 로컬 HTML로 작업하고, 최종 등록 시에는 이미지로 변환**합니다.

이 작업은 89개 상품의 가격 반영, 개별 이미지 캡처, 경로 매핑 등 대량 반복 작업이 수반되므로 **AI 에이전트(Kiro) 기반으로 진행해야 공수가 대폭 줄어들며, 수작업으로는 현실적으로 어렵습니다.**

---

## 폴더 구조

```
├── 작업용.html              ← 메인 작업 파일 (가격/디자인 수정은 여기서)
├── kakao_final_260804.html  ← 최종 산출물 (카카오 편집기 붙여넣기용)
├── assets/                  ← 상단 비주얼 소스 이미지 (로고, 배경)
├── final/                   ← 엑셀 데이터
│   └── new.xlsx               (품번, 상품명, 택가, 톡딜가, 쿠폰가)
├── generated/               ← 캡처 이미지 (서버 업로드용)
│   ├── 01_main_visual.jpg     상단 메인
│   ├── 02_kakao_channel.jpg   톡채널 버튼
│   └── cards/                 89개 상품 카드 이미지 (01~89.jpg)
├── html/                    ← 상품별 상세 페이지 HTML (89개)
└── image/                   ← 상품 촬영 이미지 원본 (89개)
```

## 작업 순서

### Step 1. 엑셀 데이터 준비

`final/new.xlsx`에 상품 데이터를 정리합니다.

| 열 | 내용 |
|----|------|
| A | 순서 (1~89) |
| B | 품번 |
| C | 상품명 |
| D | 택가 (정상가) |
| E | 톡딜가 |
| G | 혜택가 (톡딜 혜택가) |

할인율 = `ROUND((1 - 혜택가/택가) × 100)`

### Step 2. 작업용.html 디자인/수정

`작업용.html`에서 디자인 작업을 합니다. 로컬 브라우저에서 확인하면서 자유롭게 수정하세요.

- 상단: 메인 비주얼, 톡채널 버튼, 방송혜택, 톡딜혜택
- 하단: 89개 상품 카드 (2열 배치)
- 각 카드: 구성번호, 상품이미지, 컬러칩, 상품명, 정상가/톡딜가/혜택가/할인율

### Step 3. 가격 데이터 반영

에이전트에게 엑셀 기준으로 `작업용.html`의 가격을 일괄 업데이트 요청합니다.

### Step 4. 이미지 캡처

puppeteer로 상단 영역 + 89개 카드를 각각 JPG로 캡처합니다.
- 상단 4개 → `generated/` 폴더
- 카드 89개 → `generated/cards/` 폴더

### Step 5. 서버 업로드

캡처된 이미지를 서버에 업로드합니다.

| 용도 | 서버 경로 |
|------|-----------|
| 상단 프로모 이미지 | `img/outdoor2026/promotion/detail_image/` |
| 상품 카드 이미지 | `img/outdoor2026/promotion/cards/` |
| 상품 상세 HTML | `img/outdoor2026/promotion/kakao_detail/` |

### Step 6. 카카오 스토어 등록

`kakao_final_YYMMDD.html` 내용을 카카오 스토어 상품상세 HTML 편집기에 붙여넣습니다. **모바일 미리보기 필수 확인.**

## 수정이 필요할 때

| 변경 사항 | 해야 할 일 |
|-----------|------------|
| 가격 변경 | 엑셀 수정 → 작업용.html 반영 → 카드 이미지 재캡처 → 서버 재업로드 |
| 디자인 수정 | 작업용.html 수정 → 해당 영역 이미지 재캡처 → 서버 재업로드 |
| 상품 추가/삭제 | 엑셀 + 작업용.html 수정 → 전체 재캡처 |
| 컬러칩 변경 | 작업용.html에서 hex 값 수정 → 해당 카드 재캡처 |

---

## 주의사항

1. 카카오 편집기에 인라인 style HTML 직접 넣기 **금지** — 반드시 이미지로 변환
2. 고정 px 너비 사용 금지 (모바일 가로 스크롤 발생) — 이미지 기반이면 자동 스케일
3. 톡채널 버튼 이미지에 `<a href="플친URL">` 링크 필수
4. 구성 86~89 (양말)은 혜택가 없이 톡딜가만 노출

## 기술 스택

- Node.js + puppeteer (이미지 캡처)
- sharp (이미지 변환/압축)
- xlsx (엑셀 파싱)
- 이미지 호스팅: img.childy.kr
