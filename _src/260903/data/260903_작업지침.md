## 가격 표시 규칙

- **할인율**: `ROUND((1 - 혜택가/택가) * 100)`% (소수점 없음)
- **혜택가 == 톡딜가**인 경우: 혜택가 행 생략 (톡딜가만 표시)
  - 해당 구성: 1~5, 15~16, 49~56, 95~98 (양말류 포함)
- **혜택가 ≠ 톡딜가**인 경우: 정상가 + 톡딜가 + 혜택가 3단 표시

## 로컬 확인용 HTML 생성 규칙

매 회차 작업 완료 시, `preview/{회차}_로컬확인.html`을 반드시 생성한다.
- 카드 링크(`<a href>`)를 상대경로(`../img/...`)로 변환한 버전
- 브라우저에서 직접 열어 카드 클릭 → 상세 페이지 → 이미지 로드 확인 가능
